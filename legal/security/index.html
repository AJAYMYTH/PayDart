Security & Air-Gap Policy

PayDart's cryptographic guarantees, air-gapped architecture, and step-by-step verification guide.

Last Updated: September 2026

1. Air-Gapped Guarantee

Unlike virtually all mainstream mobile financial utilities, PayDart enforces a zero-trust network policy at the OS level:

  • No Internet Permission: The app does not request android.permission.INTERNET or android.permission.ACCESS_NETWORK_STATE in AndroidManifest.xml.
  • Physical Isolation: The Linux kernel sandbox prevents the app process from creating TCP/UDP sockets or transmitting data packets to any IP address.
  • Volatile Memory Only: Camera frames are converted to temporary buffers, scanned by the local ML Kit C++ engine, and recycled immediately by the Android garbage collector. No image files are persisted.

2. How to Verify Android Permissions

You can independently verify that PayDart has zero internet access using Android's native command-line tools:

Check Manifest Permissions via ADB 
# Dump declared permissions of PayDart
adb shell dumpsys package com.paydart.app | grep "permission:"

# Expected result:
# android.permission.CAMERA
# android.permission.VIBRATE
# (Notice android.permission.INTERNET is completely absent!)

3. APK Integrity & SHA-256 Checksum

Every official release APK published on GitHub Releases includes an authoritative SHA-256 hash. Before installing on your device, you can verify that the file has not been tampered with:

Verify APK Checksum 
# macOS / Linux
sha256sum app-debug.apk

# Windows PowerShell
Get-FileHash app-debug.apk -Algorithm SHA256

4. Decompilation & Source Auditing

PayDart's binaries are compiled directly from this open-source repository. You can verify the APK contents using open-source decompilers such as JADX:

Decompile and Inspect 
# Install jadx and decompile APK
jadx app-debug.apk -d paydart-decompiled

# Inspect AndroidManifest.xml and source tree
cat paydart-decompiled/resources/AndroidManifest.xml

5. Reporting a Security Vulnerability

If you discover a security vulnerability or security bug, please report it privately via GitHub Security Advisories or by emailing the project maintainer at javaliajayakumar8574@gmail.com.
