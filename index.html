UNDER THE HOOD

Architected for Extreme Efficiency.

Every line of Kotlin and Jetpack Compose is optimized to eliminate garbage collection pauses, IPC blocking, and render lag.

C++ ML Detector Pre-warming

ML Kit's native libbarhopper_v3.so typically imposes a 400ms initialization penalty on the first scanned frame. PayDart primes the native engine in a background thread at startup with a 1x1 synthetic bitmap.

Result: First-scan latency drop from 450ms → 8ms.

100% Air-Gapped Privacy

PayDart does not declare android.permission.INTERNET in its manifest. By fundamental operating system design, it is physically impossible for the app to send your camera frames, payees, or device info anywhere.

Guaranteed by Android OS security sandbox.

Zero-Delay Intent Handoff

Bypasses the slow Android system createChooser dialog which stalls the UI thread for 400–800ms. Dispatches direct package intents with overridePendingTransition(0, 0) for seamless zero-latency handoff.

Zero window animation latency.

Photo Picker Screenshot Scan

Need to pay a bill or friend from a screenshot or saved payment QR? Integrated Android Photo Picker lets you select any image securely without asking for broad file storage permissions.

Zero file system permission prompts.

Zero-Allocation UPI Parser

Pure Kotlin parser strictly extracts and sanitizes standard NPCI UPI parameters (pa, pn, am, cu, tn, mc) in 0.1ms with zero regex backtracking penalties or runtime heap overhead.

Fully NPCI Unified Payments Interface compliant.

Zero Background Footprint

PayDart terminates camera analysis immediately upon QR detection via atomic flags. It runs zero background services, zero push notification receivers, and consumes zero battery when closed.

0% background battery drain.

COMMON QUESTIONS

Frequently Asked Questions.

Everything you need to know about security, privacy, and how PayDart integrates with UPI.

Is PayDart safe to use for financial transactions?

Absolutely. PayDart is 100% open-source and declares zero network permissions (no android.permission.INTERNET). It is physically incapable of transmitting camera frames, payee VPAs, or metadata over the web. Furthermore, PayDart never handles money or bank credentials—it merely reads the QR string and hands off to your official, bank-certified UPI application.

Does PayDart ever ask for or see my UPI PIN?

Never. PayDart does not and cannot access your UPI PIN or banking details. When you scan a QR code, PayDart only passes the payee address and transaction amount to your chosen UPI app (such as Google Pay, PhonePe, or BHIM). You authenticate and enter your UPI PIN exclusively inside the secure, encrypted sandbox of your bank’s app.

How does PayDart scan so much faster than other apps?

Traditional payment apps run heavy splash screens, load dozens of ad networks, fetch user loan balances, and query tracking servers before even powering on the camera sensor. PayDart is a single-purpose native utility: it asynchronously pre-warms the C++ barcode detector and dispatches direct Android intents with zero window animation delay, achieving scanning times under 10ms.

Can I scan a payment QR code from a screenshot or WhatsApp?

Yes. PayDart integrates the modern Android Photo Picker. Tap the image icon in the top HUD to select any saved screenshot or photo. It parses the QR code locally using ML Kit and launches your UPI app immediately without requiring broad file storage permissions.

What permissions are required by PayDart?

Only android.permission.CAMERA is required to render the live viewfinder and scan QR codes. PayDart also uses android.permission.VIBRATE for haptic feedback upon detection. No internet, location, contact, or file storage permissions are requested.

Why download from GitHub Releases instead of the Play Store?

Distributing directly via GitHub Releases ensures you receive a 100% pure, unadulterated binary directly compiled from source code, free from proprietary store wrappers, forced telemetry, or licensing restrictions. You can verify the exact SHA-256 hash or build it yourself using Gradle.
